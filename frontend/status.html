Manueller Import

Der Import läuft geschützt über GitHub Actions. Dazu ist ein GitHub-Konto mit Schreibzugriff auf das Repository erforderlich; die öffentliche Website selbst erhält keine Zugangsdaten.

Manuellen Import in GitHub Actions starten

Wähle dort „Run workflow“ und anschließend die Quelle. Ergebnis und Fehler werden danach hier protokolliert. Ein fehlgeschlagener Import soll vorhandene veröffentlichte Menüdaten nicht ersetzen.
